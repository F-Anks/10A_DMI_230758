 ## Descripción

Este repositorio documenta las prácticas y proyectos realizados para la asignatura de **Desarrollo Móvil Integral**, correspondiente a la carrera de Ingeniería en Desarrollo y Gestión de Software en la UTXJ.

El propósito central de este repositorio es aplicar los principios del desarrollo de aplicaciones móviles multiplataforma utilizando **Flutter** y **Dart**. El contenido abarca el proceso completo de desarrollo: desde el maquetado de interfaces basadas en *widgets*, la gestión del estado y la implementación de la navegación, hasta la integración con servicios externos y la preparación para el despliegue final de la aplicación.

Dentro del directorio de cada práctica podrás encontrar el código fuente, el objetivo de aprendizaje específico de esa actividad y las evidencias visuales (capturas de pantalla) de la aplicación en funcionamiento.
